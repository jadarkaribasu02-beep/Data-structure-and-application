# C Programming Practice

This repository is my personal practice space for learning **C programming step by step**. I use it to write programs, test concepts, solve problems, fix errors, and track my progress as a beginner.

## What I am doing here

- Practising C syntax and core programming concepts.
- Writing small programs for each topic instead of only reading theory.
- Learning how input, conditions, loops, arrays, functions, pointers, and structures work.
- Solving problems, checking edge cases, and improving my logic.
- Keeping my code organised so I can revise it before exams and interviews.
- Recording mistakes and what I learned from them.

## How to use this repository

1. Pick one topic folder.
2. Read the example program and understand each line.
3. Run it yourself.
4. Change the input or code and predict the output before running it again.
5. Add your own practice programs with clear file names.
6. When something fails, fix it and write down the lesson in a comment or a topic notes file.
7. Commit your progress to Git regularly.

## Compile and run

You need a C compiler such as GCC. Open a terminal inside the folder containing the `.c` file.

**Compile:**
```bash
gcc hello_world.c -o hello_world
```

**Run on Windows PowerShell:**
```powershell
.\hello_world.exe
```

**Run on Linux/macOS:**
```bash
./hello_world
```

For another file, replace `hello_world.c` and `hello_world` with that file's name.
